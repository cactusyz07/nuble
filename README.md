Welcome to **Nuble** — the flagship 2026 gaming client designed for maximum multi-account performance, premium responsive UI aesthetics, and zero-emulation direct gameplay on Windows, macOS, and Linux.

## 🌟 Premium Features
- **Modern 2026 UI Design**: Experience sleek glassmorphism, fully responsive options windows, and elegant typography.
- **Robust Multi-Account Manager**: Seamlessly switch between up to 10 active game windows instantly using system-wide global shortcuts (`Alt+1` through `Alt+0`).
- **Zero-Emulation Architecture**: Directly loads official game files via native high-performance Electron wrappers for blazing fast gameplay with zero emulator detection risks.
- **Enhanced Privacy & Anti-Tracking**: Strict Content Security Policies automatically block background tracking telemetry.

## 📦 Supported Platforms
Nuble works perfectly on:
- **Windows** 10 and newer (ia32/amd64/arm64)
- **macOS** 10.15 and newer (Intel & Apple Silicon M1/M2/M3)
- **Linux** (Debian / Ubuntu / Arch) (amd64)

## 🛠️ Development & Installation

### Install the project
```sh
$ git clone https://github.com/cactusyz07/nuble.git
$ cd nuble
# install dependencies
$ yarn install
```

### Start in Debug/Developer Mode
```sh
$ yarn dev
```

### Build Production Standalone Installer
```sh
$ yarn build
```
